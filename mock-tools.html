البيانات وملف JSON

بيانات البداية في public/data/db.json. التعديلات تُحفظ تلقائيًا في localStorage لهذا الموقع والمتصفح. ملف المشروع لا يتغيّر تلقائيًا.

الاستيراد وإعادة الضبط يستبدلان بيانات المحاكاة. التصدير لا يتضمن الجلسات. بيانات المستخدمين وكلمات المرور التجريبية موجودة؛ استخدم بيانات وهمية فقط.

تجربة التأخير والأخطاء

التأخير والفشل يخصّان هذا التبويب. افتح الأدوات في نفس التبويب، اضبط الفشل ثم ارجع للتطبيق. الخطأ التجريبي 503 يحدث قبل تعديل أي بيانات، ويصيب أول طلب API بعده. عند الرجوع يُعاد تحميل التطبيق، فإذا كنت مسجّلًا يكون أول طلب غالبًا /api/auth/me.
